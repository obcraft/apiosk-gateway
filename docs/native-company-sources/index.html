01

source provenance

Add explicit publisher, transport operator, source class, countries, authority mapping, licence and observed/update timestamps to source metadata and normalized results.

Sirenic and GLEIF must not silently stand in for full native national-register coverage.

02

typed identity

Reuse existing national fact types where meaning matches; add scheme-qualified facts only where needed. Preserve country with every ID and bind profiles to the resolved subject.

KRS/NIP/REGON, IČO/internal IDs and court-qualified German IDs are not interchangeable.

03

bounded adapters

Add narrow read-only adapters under the existing executor public-source path, using allowlisted origins/routes, bounded pages/response size, declared auth, timeouts and source-specific error handling. Normalize before settlement/cache.

A successful JSON response must match requested identity and schema before being sold as a company record.

04

registration and prices

Create new listings inactive/unverified, register exact method/path/input schemas and source contracts, and set price only after access terms and bounded costs are known.

A draft catalogue is not an activation migration. Leave UUIDs, secrets and unreviewed prices out of these files.

05

country routing

Extend eu.company.profile source_operations using exact accepted execution contract IDs after admission; prefer verified native identity for the requested country, then explicitly labelled supplementary coverage.

Public browse aliases and search hits are not executable contracts. Preserve Apiosk-first precedence and subject bindings.

06

document boundary

Register profile, filing list, document download, accounts and financial extraction separately; retain period, currency, unit scale, taxonomy and standalone/consolidated basis.

A filing index, last-account year or document URL does not contain financial values.

07

bulk refresh

For bulk sources maintain full-snapshot plus delta ingestion, per-object cursors, tombstones, snapshot date and licence in a local index. Query the index through the normal executor.

A bulk CSV/SFTP source cannot be proxied as a live single-company endpoint.

08

result status

Represent found, not_found, restricted, unavailable, unsupported and ambiguous distinctly. Unknown financial values remain null with reasons.

Empty data or access failure must not become a false negative, zero turnover or company clearance.

09

quote and recovery

Retain one total price/cap, one approval, backend execution, immutable source mapping, idempotency and saved-result recovery. Reserve document fan-out in the quote and do not auto-replay paid requests.

Multiple registry steps must keep the existing purchase contract.

10

activation proof

Before advertising support: authenticated upstream probe, meaningful normalization tests, catalog validation, exact migration, executor deployment, live catalog readback and one bounded approved execution with saved-result reuse.

The present read-only catalog snapshot and direct probes establish only their stated evidence levels.
